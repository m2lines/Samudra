# Viewer development

Follow **Development and tests** in [README.md](README.md). Use a separate
`codex/viewer-<change>` branch from the latest `origin/codex/observation-viewer`
for each task. Run the viewer suite on the combined tree before fast-forward
integration; never force-push the integration branch or edit the live checkout.

For deployment, follow [the service workflow](deploy/samudra-viewer/SKILL.md).
