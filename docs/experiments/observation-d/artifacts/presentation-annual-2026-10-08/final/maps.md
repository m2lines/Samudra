# Matched annual maps

All three fixed January starts are included. The same models, reference support,
training-climatology anomalies, and color scales apply at both leads. Each map
cell occupies two pixels in each direction at native image size. Every figure
includes observations; U-global initialized persistence is the shared map control.
The score CSV also supplies every model's own persistence.
