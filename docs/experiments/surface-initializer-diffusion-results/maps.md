# Diffusion pilot map gallery

See the [results and calibration limitations](index.md). These are 550 m salinity anomalies relative to the same monthly climatology. Every anomaly/error panel uses the common scale below, with a 360 × 180 grid rendered at exactly 2 × 2 pixels per cell. Open each image at full size. Members 0 and 1 were fixed in advance, not chosen for resemblance to truth. Spread panels have their own common nonnegative scale across all six dates.
