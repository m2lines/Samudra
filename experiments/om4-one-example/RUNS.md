## Current result: non-residual texture reduction repeats, with a boundary tradeoff

The original absolute-output architecture can fit these smooth fields much more accurately. Keeping a spatial-error term during L-BFGS continuation reduces high-pass error by **105–129×** relative to matched MSE-only L-BFGS, while also reducing state MSE **6.2–14.1%**. The effect repeats in two October initialization seeds and a separately fitted January example. Each pair starts from exactly identical predictions at its own completed spatial-loss Adam checkpoint, keeps BatchNorm fixed, uses all77outputs, and has similar gradient-evaluation counts and wall time.

| Single-example context | MSE-only state MSE | Spatial-loss state MSE | High-pass MSE reduction | Worst all-channel global texture RMS / target |
| --- | ---: | ---: | ---: | ---: |
| October20, seed15 | 1.42967e-6 | 1.22854e-6 | 128.8× | 3.28% |
| October20, seed16 | 1.23758e-6 | 1.09820e-6 | 105.4× | 3.51% |
| January23, seed15 | 1.22352e-6 | 1.14794e-6 | 120.2× | 2.71% |

The objective is `MSE(pred-target) + 100*MSE(H(pred-target))`, with H equal to center minus the four-neighbor mean. Both losses use the fixed normalized channels; the spatial term excludes coast/mask edges and latitude endpoints and wraps longitude. It penalizes **spatial structure in the error**, not structure in the predicted field: the exact target has zero penalty. No output filtering, residual input skip, new parameters, or temporal feedback is used. The coefficient is unchanged across contexts. Raw-grid CPUfloat64 verification reproduces all77 channel MSEs and both aggregates, with exact prepared target/mask identity.

**Limit:** near-clean state maps are not zero error or accurate tiny increments everywhere. In the fixed quiet patch, deep-temperature texture error is0.96–1.25% of target texture RMS and SSH0.94–1.20%. Deep salinity remains13.2–19.6%; its fine-scale error is1.02–1.43× the true five-day increment RMS. Its state MSE relative to persistence is0.735/1.030/0.394 for the three contexts. Global averages hide this harder quiet-salinity case. The endpoints are still improving, not certified minima. January is another training example fitted separately, **not held-out generalization**.

**Boundary tradeoff:** the improvement is not uniform over wet cells. An exact additive partition shows interior state-error contributions improve8.45–9.93×, while contributions from wet cells excluded by the four-neighbor stencil worsen4.36–4.87×. These cells average10.53% of wet cells per channel but contain89.0–90.4% of the spatial-arm remaining MSE, versus17.4–17.8% in MSE-only arms. This is why a very large interior texture improvement yields only a modest total-MSE improvement. The category is wet mask/latitude boundaries, not land; this diagnostic does not establish an architectural coastal defect. [Partition figure](report/spatial-confirmation/boundary-error.png), [exact contributions](report/spatial-confirmation/boundary-error.json). The completed boundary-aware test below addresses most of this error redistribution, with a remaining quiet-salinity tradeoff.

This identifies a repeatable optimization/objective remedy and strongly contradicts a hard architectural inability to represent smooth output. It does not uniquely identify the source of every artifact in the official autoregressive model. Temporal backpropagation is unnecessary for the single-example texture to occur. Tested dilation/cap/upsampling changes, BatchNorm statistics, and update rounding did not provide comparable remedies; those controls have finite scope.

A practical Adam-only recipe is still unresolved. Two same-checkpoint10,000update Adam restarts remain33× worse in state MSE and51× worse in high-pass error than spatial L-BFGS for the better restart, at similar gradient counts (10,101 versus11,278); L-BFGS takes1.48× the wall time. [Measured optimizer cost](report/optimizer-cost/optimizer-cost.png). The completed matched Adam epsilon1e-8 versus1e-12 control improves stateMSE only0.156% and high-passMSE0.197%; denominator damping is not a comparable remedy under this protocol. [Verified epsilon results](report/adam-epsilon/summary.json). No full-training or rollout-stability confirmation has been launched.

Before choosing a full-training recipe, check the boundary-aware variant to address the measured error redistribution. For subsequent full-training confirmation, preserve the original absolute-output architecture and compare ordinary MSE against the fixed spatial-error objective using matched initialization, data, schedule and training budget. Report both physical state errors and fine-scale errors across every depth, and evaluate long rollouts. The single-example L-BFGS result establishes representability and an optimization route; it does not establish that stochastic full-training L-BFGS is practical, or that ordinary Adam with this loss will achieve the same endpoint.

**User steering:** residual models have historically improved short-term fits but become unstable in their rollouts. Treat residual variants as diagnostics, not the leading deployment remedy. The **absolute-output spatial-error penalty** now reduces fixed state MSE **3.60×** and high-pass error **193.89×** at weight100 versus a simultaneous ordinary-MSE control after5,000updates. ## Gradient directions and frozen output head

This is a convex quadratic fitting problem but finite optimization is not a certificate of the minimum. Head checkpoints saved every ten outer iterations; interrupted gradient diagnostics can be recomputed. All use the original 5,000-update checkpoint rather than a selected continuation endpoint.

The 4×4 and 8×8 template energies are also small; no statistical null comparison has yet been made. Values stored in `results/optimizer-probe/global-parity.json`.
