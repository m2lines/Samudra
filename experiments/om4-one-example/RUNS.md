## Current result (investigation still running)

A strong candidate now awaits replication: predicting a correction to the latest input, with a zero-initialized output head, reduces overall MSE **15.31-fold** and high-pass error MSE **16.86-fold** versus the matched absolute-output control after the same 5,000 updates. The deep-ocean maps become substantially smoother without an output filter. This is one seed and one training example, not yet a confirmed general remedy. Two new matched seeds and the missing latest-input/random-head control are queued.

The successful initial prediction is persistence: `prediction = latest_input + network_correction`, with the correction head initialized to zero. The initial backbone weights are identical across arms. Zero head **without** the input skip performs much worse, so the result is not explained by zero initialization alone. First-input residuals use October 10 as the anchor; latest-input residuals use October 15; both predict October 20 and use both input times. This is a fixed input-to-output skip, not temporal backpropagation or a latent-state intervention. Adding the skip changes the model's output parameterization and should not be described as proof that the original absolute-output function class has unlimited capacity.

## Gradient directions and frozen output head

Torch diagnostic job **20253427**, afterany **20253178**, same RTX routing, 30-minute limit and requeue, scratch outputs `diagnostics`. Callback job **20253438**, webhook **638813ce-aa72-4816-a8af-a965010f2603**, 90-minute fallback. Verified pending on dependency with correct requeue/comment/constraint/partitions.

`diagnose.py` measures gradients for total MSE, local-curvature error, complementary coarse error, and five variable groups, with frozen BatchNorm throughout. It reports gradient cosine similarities and actual finite-parameter-step loss changes. Fine/coarse terms are not an orthogonal MSE decomposition. Then it freezes all backbone features and fits the first 77 outputs of the linear convolutional head with LBFGS (100 outer iterations, up to ten internal iterations each, plus line search). This is a convex quadratic fitting problem but finite optimization is not a certificate of the minimum. Head checkpoints saved every ten outer iterations; interrupted gradient diagnostics can be recomputed. All use the original 5,000-update checkpoint rather than a selected continuation endpoint.

A preliminary check of the original saved residual found that a globally repeated 2×2 mean-offset template explains at most 0.043% of high-pass residual energy across deep U/V/T/S and SSH. Thus the visible texture is not explained by one fixed global checkerboard offset. This does not rule out spatially varying lattice artifacts or local high-frequency noise. The 4×4 and 8×8 template energies are also small; no statistical null comparison has yet been made. Values stored in `results/optimizer-probe/global-parity.json`.

`spatial_probe.py` reproduces the fixed-template calculation, a fully wet South Pacific patch comparison, and cross-channel high-pass-map cosine similarities. The initial fixed-pair residual is not strongly shared between U/V and temperature (maximum absolute map cosine about 0.036/0.074 across their depth pairs). This is not a causal exclusion of channel interaction. Intermediate-map checks found only about 0.03–0.09 high-pass-map cosine between initialization and final residual for the selected deep fields/SSH, versus about 0.48–0.55 between update 1,000 and update 5,000; this argues against simply retaining an unchanged initial noise map.
