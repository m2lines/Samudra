# Large all-fields classifier preparation

The reference is the [original all-fields regression experiment](../output-task-comparison/README.md), using its final 25k checkpoint at `/scratch/jr7309/skyline-comparison-20261106/all_fields-25k/latest.pt`. The planned classifier matches the original 207.97M-parameter all-fields regressor's 16-block, width-1024, eight-head backbone and 33×33 native quarter-degree crop. Its 8,192-category output head brings the total to 216.37M parameters. It predicts u, v, temperature and salinity at a sampled depth, with SSH supervised on surface draws. Inputs remain continuous. Training uses two-hot cross entropy and Gaussian-smoothed head initialization with sigma four bins. Each field/depth channel has its own fixed centers in normalized units, using the training-audited asinh-spaced bounds from the small classifier. Point forecasts use argmax category centers.

The fresh 25,000-update run preserves seed 20261106, four GPUs, microbatch 32, two accumulation steps, effective batch 256, 128 crops per loaded time window per GPU sampled across depths, the same input-only coverage proposal, EMA and the original learning-rate schedule. Warmup lasts 200 updates, peak learning rate is 0.0002, and cosine decay ends at 0.00002. Validation retains the original eight dates and 64 points per depth per date, with additional early checkpoints. Validation frame caching retains loaded frames in memory across evaluations while preserving the fixed dates and sampled points. [Training configuration](train.json) and [20-update qualification configuration](qualify.json) define the runs.

CPU reconstruction verified identical non-head initial tensors between the original source and the classifier source. The attention block, data extraction and coverage/sampling implementations match between those source commits. The categorical head consumes additional random draws after backbone and field-query initialization. [Initialization audit](initialization-audit.json.gz) records counts, hashes and its scope. Remote checkpoint verification remains pending.

Preparation is complete locally. Torch SSH timed out during submission preparation, so there are no submitted jobs as of this record. Once access returns, the workflow will verify the reference checkpoint, qualify the four-GPU classifier, measure runtime, and submit training. The original regression took approximately 17.4 wall hours on four GPUs, or 69.45 GPU-hours. Qualification will refine the classifier estimate.

The evaluation plan compares raw and EMA validation curves, final 25k EMA full-state predictions on test origin 4273, forecasting July 21, 2016 from the July 11 and July 16 input states, all channel/depth errors, and velocity increments measured as prediction minus latest input. Diagnostics will report their RMS magnitude and directional alignment with the true five-day increment, along with forecast RMSE improvement over persistence. It also compares the saved original large-regression regional velocities and the existing Samudra full-state forecast. This is an experiment/results record that is not intended to merge.
