Three fresh regression arms compare output tasks at 25,000 optimizer updates: temperature at a sampled depth; four physical fields at a sampled depth plus surface-only SSH; and all 77 field–depth channels at once (four fields × 19 depths + one SSH channel). The fields are temperature, salinity, zonal velocity, meridional velocity, and SSH. The first two layouts use one and five query slots; the column layout uses 77. In the five-slot layout SSH is masked out of attention and loss at depths other than the uppermost 2.5 m layer. Dry column queries are also masked. Every query attends jointly with the ocean tokens in all 16 dense transformer blocks.

All arms initialize the same parameters from seed 20261106, including the shared scalar regression head and field/depth embeddings. They use two input states, a native quarter-degree 33×33 crop, and a five-day target. Dates, sampled depths, crop locations, and coverage proposals are paired across arms. Four GPUs, microbatch 32, and two accumulation steps give 256 crops per optimizer update and 6.4 million accepted crop draws per arm. The column model receives more target values per crop; this comparison matches crop exposure and update count, not target count or FLOPs. This is a single-seed experiment.

The objective matches [plain Samudra MSE](../../../src/samudra/utils/loss.py): use the same per-channel normalization, zero land error, average over the full rectangular grid, then average equally over channels. There is no dynamic weighting. The temperature arm averages 19 channels; both all-field arms average 77. A deeper channel therefore contributes less for the same average wet-cell error when fewer cells are wet. SSH has one channel's coefficient, not one physical field's coefficient. Each sampled loss estimates its full-channel objective without bias. Sampled losses include exact corrections for the depth/area proposal and the input-only coverage proposal. Column corrections marginalize the auxiliary sampled depth. Weights are neither clipped nor divided by their sample sum.

AdamW uses peak learning rate 0.0002, 200 warmup updates, and cosine decay to 0.00002 at update 25,000. At update t, EMA decay is min(0.999, (1+t)/(10+t)). Checkpoints preserve optimizer, EMA, rank RNG, and frame-stream state for preemption recovery. Validation records raw and EMA weights at initialization, update 1, every 1,000 updates, and update 25,000. Each arm and every checkpoint use the same fixed eight dates and 64 area-sampled wet points per depth per date. Full-grid MSE estimates include the spatial sampling correction. Reports also retain per-channel wet-cell RMSE in physical units, area-weighted wet RMSE, and persistence scores. Temperature scores are the shared comparison across all arms. [Samudra's earlier reported map scores](../maps-continuation/README.md) use a different evaluation population and must not be substituted for this fixed validation set.

Primary comparisons use update 25,000, reporting both raw and EMA weights. Best-validation checkpoints are retained separately and are not substituted for the final-update comparison. Persistence predicts the last input value. Lower MSE and RMSE are better. Channel MSE averages over sampled locations and dates with spatial correction; wet-cell RMSE divides that estimate by the exact wet-cell fraction before taking the square root and restoring physical units. Area-weighted wet RMSE uses the uncorrected area-sampled errors. Channels are compared in their own physical units; the aggregate MSE averages normalized channels.

For the sampling equations, let A_z be total wet-cell area at depth z, a(x) cell area, N the rectangular grid size, and C the number of target channels. The base proposal is P(z,x)=a(x)/(19 A_z) over wet cells. A single-depth channel receives coefficient 19 A_z/(C N a(x)); SSH is included only for z=0. For the column arm, the location marginal is g(x)=a(x) sum_z[wet(z,x)/A_z]/19, and each wet channel receives coefficient 1/(77 N g(x)). Input-only coverage partitions a fresh pool of 8,192 such draws into up to eight geometric groups per depth, then mixes uniform-pool and equal-group sampling equally. A chosen pool occurrence with probability q receives the additional factor 1/(8,192 q).
