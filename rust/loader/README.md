# Samudra Rust data loader

The `samudra-rust-loader` extension provides persistent local Zarr readers for
Samudra's optional OM4 training and validation loader.

See the [Rust data loader documentation](../../docs/rust-data-loader.md) for
configuration, ownership, concurrency, buffer lifetimes, installation, and tests.
